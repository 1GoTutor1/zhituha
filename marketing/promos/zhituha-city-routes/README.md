# Житуха — районы и маршруты

30-секундный вертикальный проморолик в спокойной графике первого 30-секундного промо: тёмная лиловая палитра, мягкое золото, аккуратная рамка игрового экрана и неброские переходы.

## Экспорт

- `zhituha-city-routes.mp4` — 1080×1920, 30 FPS, 30 секунд, голос, музыка и встроенные русские субтитры.
- `zhituha-city-routes-silent.mp4` — та же анимация без аудио.
- `zhituha-city-routes.srt` — субтитры с таймкодами, взятыми из созданной речи.
- `preview-contact.png` — контактный лист ключевых кадров.

В ролике показаны три района, ограничение покупки кофе своим районом, расход энергии при поездке пешком/на своей машине и тарифы такси 500/700/900 ₽. Для видео оформлена демонстрационная экранная графика, а не скриншот работающего клиента.

Голос: бесплатный Edge Neural `ru-RU-DmitryNeural`. Музыка — тихая инструментальная дорожка с плавным затуханием; резких звуковых сигналов нет.

## Пересборка

```powershell
node generate-voice.mjs
node render-promo.mjs
```

Рендер использует Playwright и `ffmpeg-static` из `%TEMP%\zhituha-production-tools\node_modules`.
