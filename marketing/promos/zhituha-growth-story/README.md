# Zhituha — промо

Короткий ролик показывает работу, развитие бизнеса, приезд торговца и семейное событие. Финальный хэндл `@zhituha_bot` появляется в последние две секунды.

## Голос и сборка

Из-за бесплатного тарифа предоставленный голос Voice Library нельзя синтезировать через API. Для бесплатной озвучки выбран встроенный голос ElevenLabs **George**, модель `eleven_multilingual_v2`. Это другой голос, не клон V3.

1. Запусти `node generate-narration.mjs` и введи API-ключ в скрытый запрос терминала.
2. Скрипт создаёт свежий MP3 и словесные таймкоды.
3. Запусти `node render-growth-story.mjs`, чтобы собрать MP4 и SRT.

Текущие файлы: `zhituha-growth-story.mp4`, `zhituha-growth-story.srt`, `voiceover-elevenlabs.mp3`.
