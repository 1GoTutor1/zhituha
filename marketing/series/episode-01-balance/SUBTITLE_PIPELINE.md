# Субтитры пилота

`audio/align-subtitles.mjs` отправляет каждый WAV-фрагмент вместе с его точным текстом в ElevenLabs Forced Alignment (`POST /v1/forced-alignment`). Таймкоды берутся из word-level ответа API; скорость чтения и длительность всей реплики не используются как оценка слов.

Скрипт группирует слова в короткие фразы, сохраняет пунктуацию и ограничивает подпись двумя строками. Он создаёт `episode-01-subtitles.srt` и `audio/aligned-subtitles.json`. SHA-256 WAV-файла и текста используется для кеша: при повторном рендере неизменённые реплики переиспользуются, изменённые выравниваются заново.

`npm run episode:render` сначала обновляет выравнивание, затем пересобирает HTML-плеер и `episode-01-final.mp4`. Субтитры плавно отрисованы в безопасной нижней зоне и встроены в изображение; SRT остаётся отдельным файлом. Голосовые WAV скрипт не редактирует и не синтезирует. `episode-01-animation-only.mp4` — отдельный экспорт без аудио и субтитров.

Для локального запуска задайте ключ ElevenLabs только в окружении текущего PowerShell-процесса, затем выполните `npm run episode:render`. Ключ не добавляйте в `.env.local`, исходники, Git или сообщения чата. Если ключ не задан, сборка останавливается и не подставляет приблизительные таймкоды.

Текущая озвучка в `audio/voice-lines.json` состоит из отдельных `narration-*.wav`, `anton-*.wav` и `buyer-*.wav`. Экспорт собирает только эти подготовленные клипы и не перегенерирует голос.
