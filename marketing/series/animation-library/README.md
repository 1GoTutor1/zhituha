# Общая библиотека анимации

Библиотека извлечена из рабочего рендера пилота и используется им напрямую.

- `character-rig.mjs` экспортирует `characterSvg()` и `episodeWalker()` для сборки цельного персонажа с раздельными руками, предплечьями, кистями, бёдрами, голенями и стопами.
- `walker-runtime.js` содержит детерминированный браузерный контроллер походки: двухзвенную IK ног, чередование шагов, подъём свободной стопы, сохранение контакта опорной стопы, противофазное движение рук и перенос веса.

Для новой серии импортируй генераторы из `character-rig.mjs`, добавляй корневой SVG-элемент походки с классом `episode-walker` и атрибутами `data-id`, `data-start`/наследуемым интервалом сцены, `data-x`, `data-y`, `data-scale`, `data-phase`, `data-travel`, `data-direction` и `data-cycle`. Включи содержимое `walker-runtime.js` в страницу сцены и вызывай `renderWalkers(timeSeconds)` из функции покадрового рендера. Персонаж должен передвигаться только вместе с анимированными ногами и контактом стоп с землёй.

Система рассчитана на перемотку в произвольный момент: поза вычисляется от времени и пройденного расстояния, а не зависит от кадров предыдущего воспроизведения. Каждую новую сцену всё равно нужно ставить под её действие и проверять отдельно.
