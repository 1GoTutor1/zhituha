# 📌 ПРОЕКТ: Telegram Mini App "Житуха" (Alpha v1.0)

**ВНИМАНИЕ ДЛЯ ИИ:** Ты — ведущий разработчик этого проекта. Твоя задача — писать чистый, рабочий код без багов. Пользователь (братан) — геймдизайнер. Не задавай лишних вопросов, подхватывай контекст.

## 🎮 Суть игры
Экономическая симуляция в сеттинге "Житуха" (неоновый киберпанк/street vibe). Игроки строят бизнесы, производят товары (кофе, машины, квартиры) и продают их другим игрокам на рынке.

## 🛠 Стек
*   **Frontend:** React, TypeScript, Vite.
*   **UI:** Lucide React (иконки), Inline-styles (темная тема, неон, шрифты Space Grotesk и Manrope).
*   **Backend/DB:** Supabase (PostgreSQL, RPC, Edge Functions).
*   **Среда:** Telegram WebApp SDK.

## 📂 Архитектура (Модульная)
*   `src/App.tsx` — главный компонент, вся логика стейтов (игрок, деньги, энергия, бизнесы, таймеры), вызовы Supabase.
*   `src/constants.ts` — все константы (цены, время, шрифты, стили `S.*`).
*   `src/tabs.tsx` — UI вкладок (`HomeTab`, `MarketTab`, `BusinessTab`, `DailyRewardModal`).
*   `src/components.tsx` — переиспользуемые UI элементы (`Btn`, `Modal`, `Toast`, `BottomNav`).
*   `src/useTelegram.ts` — хук инициализации TG.

## 🗄 Структура Базы Данных (SQL)
1.  **`players`**: `id` (uuid), `telegram_id`, `nickname`, `gender`, `avatar_id`, `money`, `energy`, `phone_count`, `has_car`, `car_model`, `has_house`, `house_type`, `referred_by`, `referral_balance`, `is_subscribed`, `last_rest_time`, `daily_streak`, `last_claim`, `boost_end`.
2.  **`businesses`**: `id`, `owner_id` (FK), `owner_name`, `worker_id` (FK), `worker_name`, `biz_type` ('coffee', 'salon', 'construction', 'taxi'), `business_name`, `stock` (jsonb: `{"lada":0, "toyota":0, "apartments":0, "taxi_cars":[], "current_model":"none"}`), `car_order_end`, `build_end`, `coffee_balance`.
3.  **`market_items`**: `id`, `seller_id` (FK), `seller_name`, `item_type` ('phone', 'car', 'house'), `item_data` (модель авто/тип дома), `price`.

## ⚙️ Ключевые механики (Реализовано в Alpha)
*   **Ежедневный бонус:** 7 дней. На 7-й день дают 3500 монет + бафф x1.1 к зарплате на 24 часа.
*   **Бизнесы (цена по возрастанию):** Кофейня (15к) -> Автосалон (150к) -> Таксопарк (300к) -> Стройтрест (500к). Каждый бизнес можно назвать (только англ. буквы, проверка на уникальность через RPC `buy_business_rpc`).
*   **Таксопарк:** Машины приносят пассивный доход (Лада 500/ч, Тойота 1500/ч). Теряют 10% прочности в час. Ломаются при 0%. Ремонт платный.
*   **Стройтрест:** Строит дом за 300к и 15 минут -> на склад падает 10 квартир.
*   **Транспорт:** Лада (отдых 70с), Тойота (отдых 50с). Квартира дает +50 к макс. энергии (150).
*   **Рынок:** Атомарная покупка через RPC `buy_market_item`. Есть кнопка "Снять с продажи" (возврат на склад/в инвентарь).
*   **Продажа бизнеса:** За 50% стоимости. Автоматически удаляет все лоты этого бизнеса с рынка.

## 🚨 Важные правила для ИИ
1.  **Никогда не ломай верстку.** Не двигай кнопки без спроса.
2.  **Всегда пиши файлы целиком**, если пользователь просит "код целиком", так как он копирует их в VS Code.
3.  **Supabase-запросы:** Всегда проверяй на `error`. Для денег и инвентаря используй RPC-функции, чтобы избежать потери данных при обрыве связи.
4.  **Стейт:** При обновлении локального стейта после действий (например, склад машин) дублируй изменения в `setMyBizs` и `supabase.update()`.
