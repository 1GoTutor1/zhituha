## 🎮 Суть игры
Экономическая симуляция в сеттинге "Житуха" (неоновый киберпанк/street vibe). Игроки строят бизнесы, производят товары (кофе, машины, квартиры, телефоны) и продают их на рынке.

## 🛠 Стек
* **Frontend:** React 19, TypeScript, Vite.
* **UI:** Lucide React (иконки), Inline-styles (темная тема, неон, шрифты Space Grotesk и Manrope).
* **Backend/DB:** Supabase (PostgreSQL, RPC, Edge Functions).
* **Среда:** Telegram WebApp SDK.
* **Деплой:** Vercel (подключен к GitHub).

## 📂 Архитектура (Модульная)
* `src/App.tsx` — главный компонент. Вся логика стейтов, таймеры, вызовы Supabase, RPC.
* `src/constants.ts` — все константы (цены, время, шрифты, стили `S.*`, дефолтные цены продажи).
* `src/tabs.tsx` — UI вкладок (`HomeTab`, `MarketTab`, `BusinessTab`, `AdminTab`, `InventoryTab` и т.д.).
* `src/components.tsx` — UI элементы (`Btn`, `Modal`, `Toast`, `BottomNav`).
* `src/useTelegram.ts` — хук инициализации TG.
* `src/supabaseClient.ts` — клиент Supabase.
* `api/bot.js` — Telegram-бот (Telegraf) на Vercel.

## 🗄 Структура Базы Данных (Основное)
1. `players`: `id`, `telegram_id` (text), `nickname`, `money` (int), `energy` (int), `phone_count`, `has_car`, `car_model`, `has_house`, `house_type`, `market_slots`, `referred_by`, `referral_balance`, `role`, `is_banned` и таймеры.
2. `businesses`: `id`, `owner_id`, `worker_id`, `biz_type` ('coffee', 'salon', 'taxi', 'phone_factory', 'construction'), `business_name`, `stock` (jsonb), `coffee_balance`, `car_order_end`, `build_end`.
3. `market_items`: `id`, `seller_id`, `seller_name`, `item_type` ('phone', 'car', 'house'), `item_data` (модель/тип), `price`.
4. `promo_codes` / `promo_activations`: Промокоды и история активаций.

## ⚙️ Ключевые механики и RPC-функции (БЕЗОПАСНОСТЬ)
Все операции с деньгами и инвентарем должны идти через RPC (защита от читов и обрывов связи).
* `buy_market_item` — атомарная покупка лота на рынке.
* `buy_business_rpc` — покупка бизнеса (проверяет уникальность названия, цену и дубликаты типа).
* `sell_business_rpc` — безопасная продажа бизнеса за 50% (удаляет бизнес, возвращает деньги, чистит лоты).
* `cancel_lot_rpc` — безопасное снятие лота с рынка (возвращает предмет на склад/в инвентарь).
* `redeem_promo` — активация промокода.
* `add_referral_balance` — начисление реферальных процентов.

## 🛡️ Важные фиксы, которые УЖЕ СДЕЛАНЫ (НЕ СЛОМАЙ!)
1. **Эксплойт с машинами/квартирами:** В `listItem` добавлен стейт `sellSource` ('personal' | 'stock'). Продажа личной машины больше не списывает складскую, и наоборот. Личную квартиру теперь можно продать без стройтреста.
2. **Двойное списание денег:** В `buyLot` убрано локальное `setMoney(m - finalPrice)`. Теперь после RPC деньги перечитываются из БД (`loadData`).
3. **Слоты рынка:** Продажа личного телефона уменьшает `market_slots` в БД. Купля — увеличивает. Больше нет бесконечной инфляции слотов.
4. **Мгновенный рефреш рынка:** В `cancelLot` и `sellBusiness` добавлен вызов `loadMarket()`, чтобы лоты исчезали из UI сразу, без перезагрузки страницы.
5. **Константы:** Весь хардкод цен в `tabs.tsx` заменен на `DEFAULT_SELL_*` и `BUTTON_BATCH_*` из `constants.ts`.
6. **Безопасность БД:** Дропнуты опасные DELETE-политики RLS на `players`, `businesses`, `market_items`. Удаление теперь только через безопасные RPC.
